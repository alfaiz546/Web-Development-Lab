# P1 – Project folder and terminal navigation

## Objective
Create a project folder and practise basic terminal navigation.

## Commands (macOS / Linux)
```bash
mkdir Web-Development-Lab
cd Web-Development-Lab
pwd
mkdir P1-Project-Folder
ls
cd P1-Project-Folder
touch notes.txt
ls
cd ..
```

## Expected result
A `Web-Development-Lab` folder containing the practical folders. `pwd` prints the current path, and `ls` lists files/folders.
