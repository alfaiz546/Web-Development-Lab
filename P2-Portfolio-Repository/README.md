# P2 – Portfolio repository with an initial commit

## Objective
Create a local Git repository and make its first commit.

## Commands
Run these commands from the main project folder:
```bash
git init
git status
git add .
git commit -m "Initial commit: web development lab"
```

To connect a GitHub repository (create an empty repository on GitHub first):
```bash
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/Web-Development-Lab.git
git push -u origin main
```
Replace `YOUR-USERNAME` with your GitHub username.
